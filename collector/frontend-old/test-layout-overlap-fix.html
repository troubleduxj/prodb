📱 响应式测试说明

测试步骤：

  1. 桌面端 (> 1024px): 侧边栏宽度240px，主内容区应该有正确的margin-left和width
  2. 平板端 (768px - 1024px): 侧边栏宽度200px，主内容区应该相应调整
  3. 移动端 (< 768px): 侧边栏隐藏，主内容区占满全宽

验证清单：

  • ✅ 左边缘的红色标记完全可见
  • ✅ 黄色边缘指示器完全可见
  • ✅ 网格第一列完全可见
  • ✅ 表格第一列完全可见
  • ✅ 没有水平滚动条（除非内容确实超宽）
  • ✅ 调整窗口大小时布局正确响应

修复内容：

问题： 在平板端(max-width: 1024px)，侧边栏宽度改为200px，但主内容区的width没有相应更新。
修复： 添加了 width: calc(100% - 200px) 到平板端的 .main-content 样式中。

🔧 CSS修复详情

修复前：

@media (max-width: 1024px) {
    .sidebar {
        width: 200px;
    }
    
    .main-content {
        margin-left: 200px;
        padding: var(--space-6);
        /* ❌ 缺少 width 设置 */
    }
}

修复后：

@media (max-width: 1024px) {
    .sidebar {
        width: 200px;
    }
    
    .main-content {
        margin-left: 200px;
        width: calc(100% - 200px);  /* ✅ 添加了正确的宽度计算 */
        padding: var(--space-6);
    }
}
