## 概述

ProDB Collector 是一个工业数据采集和协议测试工具，提供简洁直观的Web界面，支持多种工业协议的连接、测试和数据采集。

### 主要功能

- **实时监控**: 查看采集器状态和数据流
- **协议测试**: 支持OPC UA、Modbus、MQTT等协议测试
- **配置管理**: 简化的接口配置和管理
- **驱动管理**: 动态加载和管理协议驱动
- **移动端支持**: 响应式设计，支持移动设备访问
- **离线功能**: PWA技术，支持离线操作

### 支持的协议

- OPC UA (OPC Unified Architecture)
- OPC DA (OPC Data Access)
- Modbus TCP/RTU
- MQTT (Message Queuing Telemetry Transport)
- Ethernet/IP
- Profinet (计划支持)

3. 首次使用会显示简单的引导提示

### 基本导航

- **仪表板**: 查看系统状态和接口概览
- **协议测试**: 独立的协议测试工具
- **配置管理**: 管理接口配置
- **驱动管理**: 管理协议驱动

### 快速操作

1. **查看系统状态**: 在仪表板查看运行时间、数据点数量等
2. **测试连接**: 使用协议测试工具验证设备连接
3. **添加接口**: 通过配置向导快速添加新接口

## 仪表板

仪表板是应用的主页面，提供系统概览和快速操作功能。

### 系统概览卡片

显示采集器的关键信息：

- **运行状态**: 采集器当前运行状态（运行中/已停止/错误）
- **运行时间**: 采集器持续运行时间
- **数据点数量**: 当前配置的数据点总数
- **错误数量**: 最近的错误统计

### 接口状态卡片

每个配置的接口都有独立的状态卡片，显示：

- **接口名称**: 用户定义的接口名称
- **协议类型**: 使用的协议（OPC UA、Modbus等）
- **连接状态**: 当前连接状态（已连接/已断开/错误/测试中）
- **数据速率**: 实时数据采集速率（点/秒）
- **最后更新**: 最后一次数据更新时间

### 快速操作

每个接口卡片提供快速操作按钮：

- **启动/停止**: 控制接口运行状态
- **测试**: 快速测试接口连接
- **配置**: 打开接口配置页面

### 自动刷新

仪表板每5秒自动刷新状态信息，无需手动刷新页面。

## 协议测试

协议测试模块提供独立的测试工具，无需完整配置即可测试设备连接。

### 测试模式

#### 单点测试

测试单个设备或接口：

1. 选择协议类型
2. 输入连接参数
3. 选择测试方法（连接、读取、写入等）
4. 点击"开始测试"
5. 查看测试结果

#### 设备扫描

自动发现网络中的设备：

1. 输入IP地址范围（如：192.168.1.0/24）
2. 选择要扫描的协议
3. 点击"开始扫描"
4. 查看发现的设备列表

#### 批量测试

同时测试多个设备或接口：

1. 导入设备列表或手动添加
2. 配置测试参数
3. 启动批量测试
4. 查看汇总结果

### 协议特定功能

#### OPC UA测试

- **连接测试**: 验证服务器连接
- **浏览测试**: 浏览服务器节点树
- **读取测试**: 读取指定节点值
- **订阅测试**: 测试数据订阅功能

#### Modbus测试

- **连接测试**: 验证设备连接
- **读取线圈**: 测试读取线圈状态
- **读取保持寄存器**: 测试读取保持寄存器
- **读取输入寄存器**: 测试读取输入寄存器
- **写入测试**: 测试写入功能

#### MQTT测试

- **连接测试**: 验证Broker连接
- **订阅测试**: 测试主题订阅
- **发布测试**: 测试消息发布
- **QoS测试**: 测试不同QoS级别

### 测试结果

测试结果包含以下信息：

- **成功/失败状态**: 测试是否成功
- **响应时间**: 测试操作耗时
- **返回数据**: 成功时返回的数据内容
- **错误信息**: 失败时的详细错误描述
- **时间戳**: 测试执行时间

### 测试报告

可以生成和导出测试报告：

- **PDF报告**: 包含测试结果和图表
- **Excel报告**: 详细的测试数据表格
- **JSON报告**: 机器可读的测试数据

## 配置管理

配置管理模块提供接口配置的创建、编辑和管理功能。

### 配置向导

新建接口时使用配置向导：

#### 步骤1：选择协议

- 从支持的协议列表中选择
- 查看协议说明和要求
- 确认协议选择

#### 步骤2：基本配置

根据选择的协议输入基本参数：

**OPC UA配置**：
- 服务器端点URL
- 安全策略
- 用户名/密码（可选）

**Modbus配置**：
- 设备地址（IP或串口）
- 端口号
- 从站ID
- 超时设置

**MQTT配置**：
- Broker地址
- 端口号
- 客户端ID
- 用户名/密码（可选）
- 主题配置

#### 步骤3：高级设置

配置高级参数：

- 数据采集间隔
- 重连设置
- 数据质量检查
- 错误处理策略

#### 步骤4：测试连接

自动测试配置的正确性：

- 验证连接参数
- 测试设备通信
- 检查数据读取
- 显示测试结果

#### 步骤5：完成配置

确认配置并保存：

- 设置接口名称
- 选择启动方式
- 保存配置
- 开始数据采集

### 配置模板

使用预设模板快速配置：

- **常用设备模板**: 针对常见设备的预配置
- **协议模板**: 基于协议类型的通用模板
- **自定义模板**: 保存和复用自定义配置

### 批量操作

对多个接口进行批量操作：

- **批量启动/停止**: 同时控制多个接口
- **批量编辑**: 修改多个接口的共同参数
- **批量删除**: 删除选中的接口
- **批量导出**: 导出接口配置

### 配置备份

自动备份和恢复功能：

- **自动备份**: 配置变更时自动备份
- **手动备份**: 创建配置快照
- **一键恢复**: 恢复到之前的配置
- **配置历史**: 查看配置变更历史

### 导入导出

支持配置的导入导出：

- **JSON格式**: 标准的配置文件格式
- **Excel格式**: 便于批量编辑的表格格式
- **模板格式**: 可重用的配置模板

## 故障排除

### 常见问题解决

#### 连接问题

**问题**: 无法连接到设备
**解决方案**:
1. 检查网络连接
2. 验证设备地址和端口
3. 确认防火墙设置
4. 检查设备是否在线

**问题**: 连接频繁断开
**解决方案**:
1. 检查网络稳定性
2. 调整超时设置
3. 启用自动重连
4. 检查设备负载

#### 数据问题

**问题**: 数据不更新
**解决方案**:
1. 检查接口运行状态
2. 验证数据点配置
3. 查看错误日志
4. 重启接口

**问题**: 数据质量差
**解决方案**:
1. 检查通信质量
2. 调整采集频率
3. 启用数据验证
4. 检查设备状态

#### 性能问题

**问题**: 页面加载慢
**解决方案**:
1. 清除浏览器缓存
2. 检查网络速度
3. 减少同时显示的数据
4. 启用数据压缩

**问题**: 内存使用过高
**解决方案**:
1. 重启浏览器
2. 关闭不必要的标签页
3. 清理缓存数据
4. 更新浏览器版本

## 常见问题

### Q: 支持哪些浏览器？

A: 支持现代浏览器：
- Chrome 80+
- Firefox 75+
- Safari 13+
- Edge 80+

不支持Internet Explorer。

### Q: 可以同时连接多少个设备？

A: 理论上没有限制，实际取决于：
- 设备性能
- 网络带宽
- 数据采集频率
- 浏览器性能

建议单个页面不超过50个活跃连接。

### Q: 数据会保存在哪里？

A: 数据保存位置：
- 配置数据：浏览器本地存储
- 缓存数据：Service Worker缓存
- 历史数据：后端数据库（如配置）

### Q: 如何备份配置？

A: 备份方法：
1. 使用配置管理的导出功能
2. 手动复制配置文件
3. 使用自动备份功能
4. 定期导出到外部存储

### Q: 忘记了设备密码怎么办？

A: 解决方案：
1. 查看设备文档获取默认密码
2. 联系设备管理员
3. 使用设备重置功能
4. 查看之前的配置备份

### Q: 应用可以离线使用吗？

A: 离线功能：
- ✅ 查看缓存的状态数据
- ✅ 编辑配置（需要同步）
- ✅ 查看历史数据
- ❌ 实时数据采集
- ❌ 新设备连接

### Q: 如何提高数据采集性能？

A: 优化建议：
1. 合理设置采集频率
2. 减少不必要的数据点
3. 使用批量读取
4. 启用数据压缩
5. 优化网络配置

### Q: 支持自定义协议吗？

A: 支持方式：
- 开发自定义驱动
- 使用通用TCP/UDP接口
- 通过脚本扩展
- 联系技术支持定制

### Q: 如何获得技术支持？

A: 支持渠道：
- 查看在线文档
- 提交问题报告
- 联系技术支持邮箱
- 参与社区讨论
