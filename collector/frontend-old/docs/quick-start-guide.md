# ProDB Collector 快速入门指南

## 欢迎使用 ProDB Collector！

ProDB Collector 是一个强大而简洁的工业数据采集和协议测试工具。本指南将帮助您在5分钟内快速上手。

## 🚀 快速开始

### 第一步：访问应用

1. 打开浏览器，访问：`http://localhost:8080`
2. 您将看到现代化的深色主题界面
3. 应用会自动加载，无需安装任何插件

### 第二步：了解界面

应用包含四个主要模块：

- **📊 仪表板** - 查看系统状态和接口概览
- **🧪 协议测试** - 独立的协议测试工具
- **⚙️ 配置管理** - 管理接口配置
- **📦 驱动管理** - 管理协议驱动

## 🎯 5分钟教程

### 场景：连接OPC UA服务器

让我们通过一个实际例子来学习如何使用ProDB Collector。

#### 1. 测试连接（1分钟）

首先，我们使用协议测试工具验证设备连接：

1. 点击 **🧪 协议测试**
2. 选择 **单点测试** 模式
3. 配置连接参数：
   ```
   协议类型: OPC UA
   服务器端点: opc.tcp://localhost:4840
   安全策略: None
   ```
4. 点击 **开始测试**
5. 查看测试结果

✅ **成功提示**: 如果看到绿色的"连接成功"，说明设备可以正常连接。

#### 2. 创建接口（2分钟）

现在创建一个正式的数据采集接口：

1. 点击 **⚙️ 配置管理**
2. 点击 **添加接口** 按钮
3. 使用配置向导：

   **步骤1 - 选择协议**：
   - 选择 `OPC UA`
   - 点击 **下一步**

   **步骤2 - 基本配置**：
   ```
   接口名称: 我的第一个OPC UA接口
   服务器端点: opc.tcp://localhost:4840
   安全策略: None
   用户名: (留空)
   密码: (留空)
   ```

   **步骤3 - 高级设置**：
   ```
   数据采集间隔: 1000ms
   连接超时: 5000ms
   自动重连: 启用
   ```

   **步骤4 - 测试连接**：
   - 系统会自动测试配置
   - 确认测试通过

   **步骤5 - 完成配置**：
   - 检查配置摘要
   - 点击 **保存并启动**

#### 3. 监控数据（1分钟）

返回仪表板查看数据采集状态：

1. 点击 **📊 仪表板**
2. 您会看到新创建的接口卡片
3. 观察实时状态：
   - 连接状态：已连接 ✅
   - 数据速率：实时更新
   - 最后更新时间：持续刷新

#### 4. 快速操作（1分钟）

在接口卡片上尝试快速操作：

- **停止**: 暂停数据采集
- **启动**: 恢复数据采集  
- **测试**: 快速连接测试
- **配置**: 修改接口设置

## 🛠️ 常用功能

### 设备扫描

快速发现网络中的设备：

1. 进入 **协议测试** → **设备扫描**
2. 输入IP范围：`192.168.1.0/24`
3. 选择协议：`OPC UA`, `Modbus TCP`
4. 点击 **开始扫描**
5. 查看发现的设备列表

### 批量测试

同时测试多个设备：

1. 进入 **协议测试** → **批量测试**
2. 添加设备列表或导入CSV文件
3. 配置测试参数
4. 启动批量测试
5. 查看汇总结果

### 配置模板

使用预设模板快速配置：

1. 进入 **配置管理**
2. 点击 **使用模板**
3. 选择适合的模板：
   - OPC UA 基础配置
   - Modbus TCP 标准配置
   - MQTT 物联网配置
4. 自定义参数
5. 一键创建接口

### 驱动管理

管理协议驱动：

1. 进入 **📦 驱动管理**
2. 查看已安装的驱动
3. 安装新驱动：
   - 本地文件上传
   - 在线驱动库
4. 配置驱动参数
5. 启用/禁用驱动

## 🔧 故障排除

### 常见问题

**Q: 无法连接到设备**
```
解决方案：
1. 检查设备IP地址和端口
2. 确认设备在线状态
3. 检查防火墙设置
4. 验证协议参数
```

**Q: 数据不更新**
```
解决方案：
1. 检查接口运行状态
2. 查看错误日志
3. 重启接口
4. 验证数据点配置
```

**Q: 页面加载慢**
```
解决方案：
1. 清除浏览器缓存
2. 检查网络连接
3. 关闭不必要的标签页
4. 更新浏览器版本
```

### 调试模式

启用详细日志：

1. 按 `F12` 打开开发者工具
2. 在控制台中输入：
   ```javascript
   localStorage.setItem('debug', 'true');
   location.reload();
   ```
3. 查看详细的调试信息
