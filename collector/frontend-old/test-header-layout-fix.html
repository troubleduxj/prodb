Header Layout Fix 测试

这个页面测试修复后的header布局，包括以下改进：

  • 优化了移动端header的响应式布局
  • 改进了breadcrumbs的显示和换行

布局特性

新的header布局具有以下特性：

  • Sticky定位：header始终保持在顶部可见
  • 响应式设计：在不同屏幕尺寸下自适应
  • 优雅降级：移动端使用简化的header布局
  • 无缝过渡：sidebar折叠时header平滑适配
  • 可访问性：支持键盘导航和屏幕阅读器
