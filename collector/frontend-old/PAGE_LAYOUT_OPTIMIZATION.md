## 🔧 修改内容

### 1. 移除面包屑导航

#### 修改前
```
仪表盘 › 配置管理 › 新建配置
```

#### 修改后
```
新建配置
```

### 2. 优化页面标题样式

#### 修改前
```javascript
.page-title {
    font-size: var(--font-size-2xl);
    font-weight: var(--font-weight-bold);
    color: var(--text-primary);
    margin: 0 0 2px 0;
    line-height: 1.2;
}
```

#### 修改后
```javascript
.page-title {
    font-size: var(--font-size-2xl);
    font-weight: var(--font-weight-bold);
    color: var(--text-primary);
    margin: 0;
    line-height: 1;
    letter-spacing: -0.02em;  /* 更紧凑的字间距 */
}
```

### 3. 简化Header布局

#### 修改前
```javascript
.header-left {
    display: flex;
    flex-direction: column;  /* 垂直布局 */
    justify-content: center;
    flex: 1;
    min-width: 0;
}
```

#### 修改后
```javascript
.header-left {
    display: flex;
    align-items: center;  /* 水平居中对齐 */
    flex: 1;
    min-width: 0;
}
```

## 🎨 统一的页面布局规范

### Header规范
```
┌────────────────────────────────────────────┐
│ [页面标题]                    [控制按钮]    │
└────────────────────────────────────────────┘
```

### 布局特点
- **高度**: 64px (固定)
- **背景**: var(--bg-secondary)
- **边框**: 1px solid var(--border-color)
- **阴影**: var(--shadow-sm)
- **定位**: sticky (粘性定位)

### 标题规范
- **字体大小**: 24px (--font-size-2xl)
- **字重**: 700 (--font-weight-bold)
- **颜色**: var(--text-primary)
- **行高**: 1 (紧凑)
- **字间距**: -0.02em (略微紧凑)

### 控制按钮规范
- **高度**: 36px
- **间距**: 12px (--space-3)
- **圆角**: 8px (--border-radius)
- **背景**: var(--bg-tertiary)
- **边框**: 1px solid var(--border-color)
