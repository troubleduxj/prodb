预期行为

当 TDengine 数据库不可用时：

  • ✅ 前端页面应该正常加载，不出现白屏或错误页面
  • ✅ 采集器管理页面应该正常工作（不依赖 TDengine）
  • ✅ 监控面板应该正常工作（使用独立的监控数据源）
  • ⚠️ 数据可视化页面应该显示友好的错误提示和设置指南
  • ⚠️ 数据库管理页面应该显示友好的错误提示和设置指南
  • ✅ 不应该在控制台看到无限重试的错误

当 TDengine 数据库可用时：

  • ✅ 所有页面都应该正常工作
  • ✅ 数据可视化功能应该能够查询和显示数据
  • ✅ 数据库管理功能应该能够管理数据库和表

TDengine 快速启动

如果需要启动 TDengine 进行完整测试：

Docker 方式（推荐）：
docker run -d -p 6030:6030 -p 6041:6041 tdengine/tdengine
Windows 服务方式：
net start taosd（需要先安装 TDengine）
