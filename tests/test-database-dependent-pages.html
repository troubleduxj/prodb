测试步骤

  1. 确保 TDengine 未运行 - 这样可以测试降级体验
  2. 访问各个页面 - 点击上面的链接
  3. 检查页面行为：
    • 页面应该正常加载，不出现白屏
    • 不应该显示 500 错误页面
    • 应该显示友好的错误提示
    • 应该提供 TDengine 启动指南
    • 应该有重试按钮
  4. 测试重试功能 - 点击重试按钮应该重新检查连接
  5. 启动 TDengine - 使用 Docker 或本地服务
  6. 验证恢复 - 页面应该自动检测并启用功能

TDengine 快速启动

如果需要测试完整功能，可以启动 TDengine：

Docker 方式（推荐）：
docker run -d -p 6030:6030 -p 6041:6041 tdengine/tdengine
Windows 服务方式：
net start taosd（需要先安装 TDengine）

故障排除

  • 页面仍显示 500 错误 - 检查前端是否重新编译，刷新浏览器缓存
  • 错误提示不显示 - 检查 DatabaseFeatureWrapper 组件是否正确导入
  • 重试按钮无效 - 检查数据库状态管理 hook 是否正常工作
  • 页面加载缓慢 - 检查 React Query 的重试配置是否生效
