🚀 使用方法

  1. 访问采集器管理页面 (/collectors)
  2. 点击"位号配置"Tab
  3. 选择要配置的采集器
  4. 在子Tab中管理位号、分组等配置

  • 响应式设计：适配不同屏幕尺寸
