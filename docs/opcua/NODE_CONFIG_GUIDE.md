# ProDB 位号配置管理指南

## 概述

ProDB 提供了强大的位号配置管理功能，允许您从 OPC UA 服务器的众多节点中精确选择需要采集的数据点。本指南将详细介绍如何配置和管理采集器的位号信息。

## 🎯 核心功能

### 1. 节点发现
- **自动扫描**: 自动发现 OPC UA 服务器上的所有可用节点
- **浏览树结构**: 支持按命名空间和路径浏览节点
- **节点信息**: 显示节点ID、数据类型、访问权限等详细信息
- **批量选择**: 支持批量选择和添加节点到采集配置

### 2. 位号管理
- **精确控制**: 从100个位号中选择90个进行采集
- **启用/禁用**: 灵活控制每个位号的采集状态
- **分组管理**: 按功能或区域对位号进行分组
- **参数配置**: 为每个位号设置采样间隔、死区值等参数

### 3. 高级配置
- **数据缩放**: 支持输入输出值的线性缩放
- **报警设置**: 配置高低限报警和优先级
- **质量监控**: 监控数据质量和连接状态
- **性能优化**: 根据重要性调整采样频率

## 📋 配置步骤

### 步骤1: 打开位号配置管理器

1. 在采集器列表中找到目标采集器
2. 点击"查看详情"按钮
3. 切换到"位号配置"标签页
4. 点击"管理位号"按钮

### 步骤2: 发现可用节点

1. 切换到"节点发现"标签页
2. 点击"开始发现"按钮
3. 系统将自动扫描 OPC UA 服务器
4. 浏览发现的节点树结构
5. 选择需要采集的节点

### 步骤3: 配置位号参数

1. 在"位号列表"中查看已添加的节点
2. 点击"编辑"按钮配置具体参数：
   - **基本信息**: 名称、描述、数据类型
   - **采样设置**: 采样间隔、死区值
   - **数据缩放**: 输入输出范围映射
   - **报警配置**: 高低限值和优先级

### 步骤4: 分组管理

1. 切换到"分组管理"标签页
2. 创建逻辑分组（如温度传感器、压力传感器等）
3. 将相关位号添加到对应分组
4. 为分组设置统一的采样参数

### 步骤5: 全局设置

1. 切换到"全局设置"标签页
2. 配置默认参数：
   - 默认采样间隔
   - 每个订阅最大节点数
   - 订阅优先级
   - 发布设置

## 🔧 配置示例

### 典型工业场景配置

假设您有一个包含100个OPC UA节点的工业系统，需要选择90个关键节点进行数据采集：

#### 节点分类和选择策略

1. **关键生产数据** (40个节点)
   - 温度传感器: 15个
   - 压力传感器: 10个  
   - 流量传感器: 10个
   - 液位传感器: 5个

2. **设备状态监控** (30个节点)
   - 电机状态和转速: 20个
   - 阀门开度: 10个

3. **系统运行参数** (20个节点)
   - 运行时间统计
   - 性能指标
   - 操作模式

#### 不采集的节点类型 (10个节点)
- 调试和测试信号
- 静态配置信息
- 备用未使用的节点
- 维护模式信号

### 采样频率优化

```json
{
  "高频采集": {

  },
  "标准采集": {
    "节点类型": "常规生产数据", 
    "采样间隔": "1000ms",
    "示例": "温度、流量、转速"
  },
  "低频采集": {
```

## 🎛️ 界面操作指南

### 位号列表界面

- **搜索过滤**: 按名称、节点ID或描述搜索
- **类型筛选**: 按数据类型筛选节点
- **分组筛选**: 按分组查看节点
- **状态筛选**: 仅显示启用或禁用的节点
- **批量操作**: 选择多个节点进行批量启用/禁用

### 节点配置对话框

- **基本信息**: 配置节点名称和描述
- **数据类型**: 显示和确认数据类型
- **采样设置**: 设置采样间隔和死区值
- **缩放配置**: 配置线性缩放参数
- **报警设置**: 设置报警阈值和优先级

### 分组管理

- **创建分组**: 按功能或位置创建逻辑分组
- **分组配置**: 为整个分组设置统一参数
- **节点分配**: 将节点分配到相应分组
- **批量操作**: 对整个分组进行批量操作

## 📊 监控和优化

### 性能监控

- **采集统计**: 监控每个节点的采集成功率
- **响应时间**: 跟踪节点响应时间
- **数据质量**: 监控数据质量状态
- **连接状态**: 实时显示连接状态

### 优化建议

1. **合理分组**: 将相似的节点分组管理
2. **采样优化**: 根据数据变化频率设置采样间隔
3. **负载均衡**: 避免单个订阅包含过多节点
4. **质量监控**: 定期检查数据质量和连接状态

## 🔄 配置导入导出

### 导出配置

1. 在位号配置管理器中点击"导出"
2. 选择导出格式（JSON/CSV）
3. 保存配置文件到本地

### 导入配置

1. 点击"导入"按钮
2. 选择配置文件
3. 预览配置内容
4. 确认导入并应用配置

### 配置模板

- **创建模板**: 将当前配置保存为模板
- **应用模板**: 将模板应用到其他采集器
- **模板管理**: 管理和维护配置模板库

## 🚨 注意事项

### 性能考虑

1. **节点数量**: 建议单个采集器不超过1000个节点
2. **采样频率**: 避免过高的采样频率导致系统负载过重
3. **网络带宽**: 考虑网络带宽限制，合理配置数据传输
4. **服务器负载**: 监控OPC UA服务器的负载情况

### 安全建议

1. **访问权限**: 确保采集器具有适当的节点访问权限
2. **连接安全**: 配置适当的安全策略和认证
3. **数据保护**: 对敏感数据进行适当的保护措施
4. **审计日志**: 启用配置变更的审计日志

### 故障排除

1. **连接问题**: 检查网络连接和OPC UA服务器状态
2. **权限问题**: 验证节点访问权限设置
3. **性能问题**: 调整采样频率和节点数量
4. **数据质量**: 检查节点配置和服务器状态
