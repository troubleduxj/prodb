## 📋 实现的功能模块

### 1. 添加/编辑位号 ✅
- **完整的表单界面**：支持所有必要字段的输入和验证

- **参数配置**：采样间隔、死区值、单位、命名空间等

- **启用/禁用控制**：实时切换位号状态

### 2. 分组管理 ✅
- **创建/编辑分组**：完整的分组信息配置

- **参数验证**：数值范围验证和合理性检查
- **设置预览**：实时显示当前全局设置
- **设置保存**：持久化全局配置

### 5. 批量操作 ✅
- **多选支持**：支持选择多个位号进行批量操作
- **批量启用/禁用**：一键批量控制位号状态

- **选择状态提示**：显示已选择的位号数量

### 6. 筛选搜索 ✅

## 📊 数据模型

### NodeConfig (位号配置)
```typescript
interface NodeConfig {
  id: string                    // 唯一标识
  nodeId: string               // OPC UA节点ID
  name: string                 // 显示名称
  description?: string         // 描述信息
  dataType: DataType          // 数据类型
  unit?: string               // 单位
  enabled: boolean            // 启用状态
  samplingInterval?: number   // 采样间隔
  deadband?: number          // 死区值
  group?: string             // 所属分组
  browsePath?: string        // 浏览路径
  namespace?: number         // 命名空间
}
```

### NodeGroup (分组配置)
```typescript
interface NodeGroup {
  id: string                  // 分组ID
  name: string               // 分组名称
  description?: string       // 分组描述
  enabled: boolean          // 启用状态
  nodeIds: string[]         // 包含的位号ID列表
  samplingInterval?: number // 分组采样间隔
  priority: number          // 优先级
}
```

### CollectorNodeConfig (采集器位号配置)
```typescript
interface CollectorNodeConfig {
  collectorId: string        // 采集器ID
  nodes: NodeConfig[]        // 位号列表
  groups: NodeGroup[]        // 分组列表
  globalSettings: {          // 全局设置
    defaultSamplingInterval: number
    maxNodesPerSubscription: number
    subscriptionPriority: number
    publishingEnabled: boolean
  }
  updatedAt: string         // 更新时间
  version: string           // 配置版本
}
```

## 📝 使用指南

### 基本操作流程
1. **进入页面**：访问采集器管理页面，点击"位号配置"Tab
2. **选择采集器**：从下拉列表选择要配置的采集器
3. **配置位号**：
   - 手动添加：点击"添加位号"按钮
   - 自动发现：点击"发现节点"按钮，然后添加发现的节点
4. **管理分组**：切换到"分组管理"Tab创建和管理分组
5. **全局设置**：在"全局设置"Tab中配置系统参数
6. **批量操作**：选择多个位号进行批量启用/禁用
